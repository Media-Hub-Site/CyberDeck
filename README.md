# CyberDeck - MediaHub Cyber Suite ⚡

**CyberDeck** es una suite de minijuegos y puzzles temáticos de hackeo/ciberseguridad para el ecosistema **MediaHub**, desarrollada íntegramente en **Python & Pygame** con síntesis procedimental de sonido (sin dependencias de archivos de audio externos).

## 🎮 Módulos de Puzzles Incluidos

### 1. Cyber Circuit (Módulo // 01)
- **Mecánica**: Bypass físico de energía enrutando cables y nodos rotatorios hacia el servidor central.
- **Controles**: Clic en cualquier nodo para rotar 90°. Conecta cara a cara la fuente y el objetivo antes de que se agote el tiempo.

### 2. Breach Protocol (Módulo // 02)
- **Mecánica**: Infiltración en la memoria RAM inspirada en el hackeo de *Cyberpunk 2077*.
- **Controles**: Alterna selección entre **Fila $\rightarrow$ Columna $\rightarrow$ Fila** para reproducir la secuencia de códigos hexadecimales requerida en el buffer sin saturarlo.

### 3. Signal Synchronizer (Módulo // 03)
- *(Próximamente)*: Ajuste de ondas senoidales y frecuencias en osciloscopio analógico.

---

## ⌨️ Atajos y Controles Globales
- **Clic Izquierdo**: Seleccionar módulo o interactuar con el puzzle.
- **[ESC]**: Regresar al Menú Principal del Deck desde cualquier minijuego (o salir).
- **[R]**: Reiniciar nivel actual.
- **[M]**: Alternar Mute / Sonido procedimental.

---

## 🚀 Instalación y Ejecución

```bash
cd CyberDeck
pip install -r requirements.txt
python main.py
```
